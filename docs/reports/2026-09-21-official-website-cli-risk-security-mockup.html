CLI safety, with context

看見異常，先理解再決定。

Navide 在 CLI pane 中呈現可驗證的網路與資料目錄觀測，讓你知道哪裡需要確認，也清楚知道系統不知道什麼。

Navide 自身 backend、renderer 與 WebSocket 不在 CLI process tree 採樣範圍。

它會顯示什麼？

提示是風險線索，不是違法判決。每個狀態都保留來源、時間與可用性，讓你能自行確認。

▲

未預期網路連線

CLI process tree 連到未驗證的 IP／port。未知主機名稱與傳輸內容不會被猜測。

◒

大型不透明檔案

成功 baseline 後，vendor 資料根目錄出現超過 100 MiB 且無法辨識格式的檔案。

↻

重現證據

檔案先出現、確認消失，再次出現才提高為紅色；失敗觀測不會被當成乾淨。

保持判斷邊界

成功觀測表示資料取得成功，不代表目的地安全；unknown 也不代表沒有風險。

不會宣稱

不宣稱法律上的違法、不宣稱完整外洩偵測，也不猜測傳輸內容或資料用途。

不會收集

不攔截封包、不上傳檔案內容；只保留必要的數值端點、路徑與觀測時間。

不會自動處置

不會刪檔、終止程序或封鎖連線；Ignore、Allow、Reveal 都由使用者操作。

隱私與程序範圍

只看 CLI 的樹

採樣以 terminal session root 與 descendants 為範圍。Navide backend、renderer、WebSocket 自身程序會排除。

localhost 也要有上下文

127.0.0.1 不會全部放行；只有能確認是合法的 CLI helper 或 Navide 自身端點，才會被正確分類。

要點zh-TWen-USja-JP
未預期網路連線命中
未預期網路連線：CLI Process Tree 中的 Process 連到預期位址集合以外的 IP／Port。Navide 只記錄數值端點，不猜測主機名稱，也不推測傳輸內容；合法工具、Proxy 或不同的 DNS 回應都可能造成不符。
命中
Unexpected network connection: a process in the CLI process tree connected to an IP/port outside the expected address set.
命中
想定外の Network 接続：CLI Process Tree 内の Process が、想定 Address 集合の外にある IP／Port へ接続した状態です。Navide は数値の Endpoint のみを記録し、Hostname を推測せず、転送内容も推定しません。正当な Tool、Proxy、異なる DNS 応答でも不一致は起こり得ます。
大型不透明檔案命中
大型不透明檔案：成功建立 Baseline 後，Vendor 資料根目錄出現超過 100 MiB、且有限度的內容檢查無法辨識格式的新檔案。檔案先出現、確認消失、再次出現且仍不透明，才會提高為紅色；這不代表內容相同，也不指出是誰移除或重建了它。
命中
Large opaque file: after a successful baseline, a new file above 100 MiB appeared in a vendor data root and bounded content inspection could not recognize its format.
命中
大きな不透明 File：Baseline の取得に成功した後、Vendor Data Root に 100 MiB を超え、限定的な内容検査で Format を識別できない新しい File が現れた状態です。File が出現し、消失を確認し、再び出現してなお不透明である場合にのみ赤に上がります。これは内容が同一であることも、誰が削除・再作成したかも示しません。
unknown／stale命中
unknown 與 stale 狀態：採集失敗、不完整或宣告不可用時，狀態是 unknown，不會被當成乾淨；先前的觀測會以 stale 標示保留。成功觀測代表資料取得成功，不代表目的地安全；unknown 也不代表沒有風險。沒有標記不是安全的保證。
命中
unknown and stale states: when collection fails, is incomplete or the declarations are unavailable, the state is unknown and is never treated as clean; earlier observations remain visible marked as stale.
命中
unknown と stale の状態：収集が失敗、不完全、または宣言が利用できない場合、状態は unknown となり、Clean とは扱われません。以前の観測は stale として表示が残ります。観測の成功は Data を取得できたことを意味し、宛先が安全であることは意味しません。unknown も Risk がないことを意味しません。Pill がないことは安全の保証ではありません。
排除 backend/renderer/WebSocket命中
只看 CLI 的樹：採樣以 Terminal Session 的 Root Process 與其 Descendants（CLI、MCP Server、工具）為範圍。Navide 自身的 Backend、Renderer 與 WebSocket 連線不在觀測範圍內，因為那是 Navide 自己。
命中
Navide's own backend, renderer and WebSocket connections are outside the observed scope, because they are Navide itself.
命中
CLI の Tree だけを見る：Sampling の範囲は Terminal Session の Root Process とその Descendants（CLI、MCP Server、Tool）です。Navide 自身の Backend、Renderer、WebSocket 接続は、Navide 自身であるため観測範囲に含まれません。
localhost 不等於安全命中
localhost 不等於安全：連到 127.0.0.1 不會一律放行。同一個 loopback 位址可能是合法的 CLI Helper、Navide 自身的端點，或任何以你的身分執行的 Process；分類依程序歸屬與上下文判斷，而不是依位址本身。
命中
localhost is not the same as safe: a connection to 127.0.0.1 is not allowed through by default.
命中
localhost は安全と同義ではない：127.0.0.1 への接続は一律に許可されません。同じ Loopback Address が、正当な CLI Helper にも、Navide 自身の Endpoint にも、あなたの権限で動作する任意の Process にもなり得ます。分類は Address そのものではなく、どの Process が所有し、どの Context にあるかで決まります。
不宣稱違法判定命中
不宣稱：不宣稱法律上的違法判定，也不宣稱完整的外洩偵測。觀測結果不證明資料外洩或不當意圖，也不猜測傳輸內容與資料用途。
命中
No claims: Navide does not claim a legal finding of illegal activity and does not claim complete exfiltration detection.
命中
主張しない：法的な違法性の判定を主張せず、完全な Exfiltration Detection も主張しません。観測結果は Data の流出や不正な意図を証明せず、転送内容や Data の用途を推測しません。
